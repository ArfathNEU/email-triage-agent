# AI Email Triage Assistant

A full-stack web app that ingests a CSV of emails and uses an LLM agent to recommend tool actions for each — schedule a meeting, draft a reply, escalate, archive, etc.

Built against the Enron Email Dataset.

## Stack

- React + Vite + TypeScript (frontend)
- Node + Express + TypeScript (backend)
- SQLite via better-sqlite3
- Anthropic Claude API (tool-use)
